# Figures du jeu de cartes

Les douze figures (valets, dames, rois) proviennent du projet **svg-cards**
de **David Bellot** — Berkeley, CA, USA, récupérées depuis Wikimedia Commons.

- Portrait français (portrait de Paris), celui des vrais jeux de belote
- Licence : **GNU LGPL, version 2.1 ou ultérieure**
- Attribution obligatoire, conservée ici et dans le pied de page de l'app

Les autres rangs (7, 8, 9, 10, as) ne sont pas des images : ils sont dessinés
en CSS à partir de la disposition classique des pointes. C'est d'ailleurs ainsi
qu'un vrai jeu est fabriqué — seules les figures sont illustrées.
